# Каталог книг (Book Catalog)

Простое консольное приложение на Python для управления каталогом книг. 
Данные хранятся в формате JSON.

## Структура данных
Файл `books.json.example` демонстрирует формат хранения данных.

## Запуск
1. Скопируйте `books.json.example` в `books.json`.
2. Запустите скрипт: `python books.py`

## Добавление книги
Функция `add_book(title, author, year)` добавляет новую книгу в каталог.
Автоматически генерирует уникальный ID.

## Поиск по автору
Функция `search_by_author(author_query)` ищет книги по частичному совпадению.
Регистр не учитывается.

## Экспорт в CSV
Функция `export_books(output_filename)` экспортирует каталог в CSV файл.
По умолчанию сохраняется в `books.csv`.

## Поиск по ISBN
Функция `search_by_isbn(isbn)` ищет книгу по точному совпадению ISBN.

## Ограничения каталога
Максимальное количество книг в каталоге ограничено константой `MAX_BOOKS = 500`.
При достижении лимита добавление новых книг блокируется с выводом сообщения.
